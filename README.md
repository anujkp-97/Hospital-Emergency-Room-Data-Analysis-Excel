# Hospital-Emergency-Room-Data-Analysis-Excel
## Overview
This project is an interactive Excel dashboard created to analyze hospital emergency room performance, patient flow, waiting time, admission status, and department referrals using dynamic visualizations and KPI metrics.

---

## Features
- Interactive Month & Year Filters
- KPI Cards
- Patient Attendance Analysis
- Gender-wise Analysis
- Department Referral Analysis
- Age Group Analysis
- Reset Buttons using VBA Macros
- Dynamic Pivot Tables & Charts

---

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- VBA Macros
- Conditional Formatting

---

## Key Insights
- Total Patients: 9216
- Average Wait Time: 35.26 Minutes
- Satisfaction Score: 4.99
- 59% Patients Experienced Delays
- Highest referrals handled in General Practice

---

## Business Impact
This dashboard helps hospital management to:
- Monitor emergency room performance
- Improve operational efficiency
- Reduce patient waiting time
- Support data-driven decisions
